## 🎯 Deployment Instructions

### 1. Upload Plugin
```bash
# Upload the entire plugin folder to:
/wp-content/plugins/sit-program-recommender/
```

### 2. Activate Plugin
- Go to WordPress Admin → Plugins
- Activate "SIT Program Recommender"

### 3. Configure OpenAI
- Go to WordPress Admin → SIT Program Recommender → Settings
- Add your OpenAI API key in "OpenAI Settings"
- Configure model settings (defaults work well)
- Save Settings

### 4. Add to Pages
```php
// Add shortcode to any page or post:
[sit_program_recommender]
```

### 5. Test Functionality
- Visit page with shortcode
- Start assessment
- Verify OpenAI questions are generated
- Complete full 10-question flow
- Check recommendations display

## 🔧 Configuration Options

### OpenAI Settings
- **API Key**: Your OpenAI API key (required for AI features)
- **Model**: gpt-3.5-turbo (default) or gpt-4
- **Max Tokens**: 500 (default)
- **Temperature**: 0.7 (default creativity level)

### Display Settings
- **Theme**: Modern (default), Minimal, or Classic
- **Progress Bar**: Show/hide progress indicators
- **Results Per Page**: Number of recommendations to show
- **Custom Branding**: studyinturkiye.com icon integrated

### General Settings
- **Statistics Tracking**: Enable/disable usage analytics
- **Rate Limiting**: API call limits for performance
- **Debug Mode**: Enable for troubleshooting
